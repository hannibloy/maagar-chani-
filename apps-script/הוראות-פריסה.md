# חיבור טופס הקשר לגיליון — הוראות צעד אחר צעד

⏱ כרבע שעה, פעם אחת בלבד. בסוף התהליך כל פנייה מהאתר תישמר בגיליון ותגיע אלייך במייל.

## שלב א — הדבקת הסקריפט בגיליון

1. פתחי את **גיליון המאגר** (אותו גיליון שממנו האתר קורא את התוצרים).
2. בתפריט העליון: **תוספים ← Apps Script** (Extensions ← Apps Script).
   נפתחת לשונית חדשה עם עורך קוד.
3. מחקי את כל מה שכתוב בעורך (השורות `function myFunction()...`).
4. פתחי את הקובץ `apps-script/contact-form.gs` מהמאגר, העתיקי את **כל** התוכן שלו,
   והדביקי בעורך.
5. למעלה משמאל לחצי על סמל הדיסקט 💾 (או Ctrl+S) לשמירה.
   אפשר לתת לפרויקט שם: `טופס קשר`.

## שלב ב — פרסום כ-Web App

6. למעלה מימין לחצי על הכפתור הכחול **פריסה ← פריסה חדשה** (Deploy ← New deployment).
7. ליד "בחירת סוג" לחצי על גלגל השיניים ⚙ ובחרי **אפליקציית אינטרנט** (Web app).
8. מלאי כך — זה החלק החשוב:
   - **תיאור:** טופס קשר (או כל שם)
   - **הפעלה בתור** (Execute as): **אני** (Me)
   - **למי יש גישה** (Who has access): **כל אחד** (Anyone)
     ⚠️ בלי זה הטופס באתר לא יעבוד. "כל אחד" מאפשר רק *לשלוח* פניות —
     אף אחד לא יכול לקרוא את הגיליון דרך זה.
9. לחצי **פריסה** (Deploy).
10. גוגל תבקש אישור הרשאות: **אישור גישה ← בחרי את החשבון שלך**.
    אם מופיע מסך "Google hasn't verified this app" — לחצי **Advanced ← Go to ... (unsafe)**.
    זה תקין: הסקריפט הוא שלך, בחשבון שלך, וגוגל מציגה את זה לכל סקריפט אישי.
11. בסיום מוצגת **כתובת Web App** שמתחילה ב-
    `https://script.google.com/macros/s/....../exec`
    — העתיקי אותה (כפתור העתקה ליד).

## שלב ג — הדבקת הכתובת באתר

12. שלחי לי את הכתובת, או ערכי בעצמך את הקובץ `site/assets/site.js`:
    בשורה שמתחילה ב-`var CONTACT_ENDPOINT = ''` הדביקי את הכתובת בין הגרשיים:

    ```js
    var CONTACT_ENDPOINT = 'https://script.google.com/macros/s/XXXXX/exec';
    ```

## שלב ד — בדיקה

13. פתחי בדפדפן את כתובת ה-Web App עצמה. אמור להופיע:
    `{"ok":true,"service":"chani-bloy-contact"}`
14. מלאי את הטופס באתר ולחצי שליחה. בדקי ש:
    - הופיעה הודעת "ההודעה נשלחה!"
    - נוספה שורה בלשונית **"פניות"** בגיליון (הלשונית נוצרת לבד בפנייה הראשונה)
    - הגיע מייל ל-bloyarava1@gmail.com

## טוב לדעת

- **עדכון הסקריפט בעתיד:** אחרי שינוי בקוד — פריסה ← ניהול פריסות ← ✏️ ← גרסה: חדשה ← פריסה.
  הכתובת נשארת אותה כתובת.
- **כל עוד הכתובת לא הודבקה באתר:** הטופס לא נכשל — הוא פותח וואטסאפ עם ההודעה
  המוכנה, כך שאף פנייה לא הולכת לאיבוד.
- מגבלת המיילים של גוגל בחשבון אישי היא כ-100 ביום — הרבה מעבר לצפוי.
